# ConnectIQ interface

Direction: **True-black flat**, seed **365398089**, selected from the design-taste-frontend app-screen draw. No redraws. Neutral dark surfaces and an inverted primary button keep the data prominent. A silicon-blue data hue replaces the dealt lime using the sheet's explicitly allowed product-face choice. The ConnectIQ mark is a connected circuit loop drawn as SVG.

The signature element is the network pipeline: eight real connection stages alongside requests and acceptances, all computed from stored prospects. There is no sample networking data in the application.

Screen questions:

| Screen | First question |
| --- | --- |
| Overview | What needs attention in my network today? |
| Discover People | Who should I research next? |
| Prospects | Which people am I considering and how are they progressing? |
| Follow-ups | Who needs a manual review or interaction? |
| Analytics | What activity and outcomes have I recorded? |
| Companies | Which semiconductor companies am I researching? |
| Settings | How is my private workspace configured? |

The shell uses a 230 px labelled sidebar, equal 29 px canvas gutters, a 14 px internal gap, 26 px titles and tabular figures. Streamlit's collapsed sidebar provides the phone navigation. Metric strips become two columns on narrow screens. Tables scroll inside their own frames. Plotly charts use straight lines, zero-based count axes, one blue series plus neutrals, and no default template backgrounds. All editable content stays in native accessible Streamlit controls.

Inter is preferred when locally available, with Segoe UI/system sans-serif fallbacks. No third-party font requests or tracking scripts are loaded. This is a documented deviation from the dealt font requirement because network access is unavailable in the build environment.
